# Contributing

## Issues

We use GitHub issues to track public bugs and feature requests. Please include a
clear description, a minimal reproduction, and your PyTorch, Python, CUDA, and
GPU versions when reporting a bug.

Meta has a [bounty program](https://www.facebook.com/whitehat/) for the safe
disclosure of security bugs. In those cases, please go through the process
outlined on that page and do not file a public issue.

## Pull Requests

We are not currently accepting pull requests. Please open an issue to discuss
proposed changes with the maintainers.

## Contributor License Agreement ("CLA")

In order to accept your pull request, we need you to submit a CLA. You only need
to do this once to work on any of Meta's open source projects.

Complete your CLA here: <https://code.facebook.com/cla>.

## Code of Conduct

Please follow our [Code of Conduct](CODE_OF_CONDUCT.md) when participating in
this project.
